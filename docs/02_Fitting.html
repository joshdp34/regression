2  Fitting the Simple Linear Regression Model

“Regression. It is a universal rule that the unknown kinsman in any degree of any specified man, is probably more mediocre than he.” - Francis Galton

The simplest model for relating a response variable \(y\) to a single predictor variable \(x\) is a straight line.

We will begin by discussing simple linear models and how to fit them to a dataset using the method of least squares.

Next, we will demonstrate how to determine whether a relationship exists between \(y\) and \(x\), and how to use the model to either estimate \(E(y)\), the mean value of \(y\), or to predict a future value of \(y\) for a given \(x\).

This collection of methods is known as simple linear regression analysis.

2.1 The Straight-Line Probabilistic Model

ExampleExample 2.1: CO₂ emissions as a probabilistic relationship

When studying environmental science, consider modeling the monthly carbon dioxide (CO₂) emissions \(y\) of a city as a function of its monthly industrial activity \(x\).

The first question to ask is: Do you believe an exact (deterministic) relationship exists between these two variables?

In other words, can we predict the exact value of CO₂ emissions if industrial activity is known?

It’s unlikely. CO₂ emissions depend on various factors beyond industrial activity, such as weather conditions, regulatory policies, and transportation levels. Even with multiple variables in the model, it’s improbable that we could predict monthly emissions precisely.

There will almost certainly be some variation in emissions due to random phenomena that cannot be fully explained or modeled.

Therefore, we should propose a probabilistic model for CO₂ emissions that accounts for this random variation:

\[ y = E(y) + \varepsilon \]

The random error component,\(\varepsilon\), captures all unexplained variations in emissions caused by omitted variables or unpredictable random factors.

The random error plays a key role in hypothesis testing, determining confidence intervals for the model’s deterministic portion, and estimating the prediction error when using the model to predict future values of \(y\).

Let’s start with the simplest probabilistic model—a first-order linear model that graphs as a straight line.

2.2 A First-Order Linear Model

The first-order linear model is expressed as \[ y = \beta_0 + \beta_1 x + \varepsilon \]

where:

  • \(y\) is the response variable
  • \(x\) is the predictor variable (sometimes called the independent variable)
  • \(E(y) = \beta_0 + \beta_1 x\) is the deterministic component
  • \(\varepsilon\) is the random error component
  • \(\beta_0\) is the y-intercept of the line (the point where the line intersects the y-axis)
  • \(\beta_1\) is the slope of the line (the change in the mean of \(y\) for every 1-unit increase in \(x\))

We use Greek symbols \(\beta_0\) and \(\beta_1\) to denote the y-intercept and slope of the line. These are population parameters with values that would only be known if we had access to the entire population of \((x, y)\) measurements.

NoteReview: Greek Letters in Notation

Usually, in Statistics, lower-case Greek letters are used to denote population parameters. In our model above, we have an exception. The Greek letter \(\varepsilon\) is not a parameter, but a random variable (parameters are not random variables in frequentist statistics).

As discussed in Section 1.2, regression can be viewed as a six-step process. For now, we’ll focus on steps 2-6, using the simple linear regression model. We’ll explore more complex models later.

2.3 Fitting the Model: The Method of Least Squares

ExampleExample 2.2: A small dataset for fitting a line

Suppose we have the data shown in Table 2.1 below and plotted in the scatterplot in Figure 2.1.

library(tidyverse)
x = c(1, 2, 2.75, 4, 6, 7, 8, 10)
y = c(2, 1.4, 1.6, 1.25, 1, 0.5, 0.5, 0.4)
dat = tibble(x, y)

dat |> 
  ggplot(aes(x = x, y = y)) + 
  geom_point()

We hypothesize that a straight-line model relates y to x, as follows:

\[ y = \beta_0 + \beta_1 x + \varepsilon \]

How can we use the data from the eight observations in Table 2.1 to estimate the unknown y-intercept (\(\beta_0\)) and slope (\(\beta_1\))?

We can start by trying some lines and see how well they fit the data. But how do we measure how well a line fits the data?

A quantitative method to evaluate how well a straight line fits a set of data is by measuring the deviations of the data points from the line.

NoteReview: Deviations of Response Variable

\(y\) is the variable of interest, so we are focused on the differences between observed \(y\) and the predicted value of \(y\)

We calculate the magnitude of the deviations (the differences between observed and predicted values of \(y\)).

These deviations, or prediction errors, represent the vertical distances between observed and predicted values of \(y\).

ExampleExample 2.3: Comparing two possible fitted lines

Suppose we try to fit the line \[ \hat{y} =2-.2x \tag{2.1}\]

This line can be seen in Figure 2.2.

dat |> 
  ggplot(aes(x = x, y = y)) + 
  geom_point() +
  geom_abline(intercept = 2, slope = -0.2, color = "red")

The observed and predicted values of \(y\), their differences, and their squared differences are shown in the table below.

Note that the sum of the errors (SE) is 0.8, and the sum of squares of the errors (SSE), which emphasizes larger deviations from the line, is 0.325.

We can try another line to see if we do better at predicting \(y\) (that is, have smaller SSE).

Let’s try the line \[ \hat{y} =1.8-.15x \tag{2.2}\]

This line can be seen in Figure 2.3.

dat |> 
  ggplot(aes(x = x, y = y)) + 
  geom_point() +
  geom_abline(intercept = 1.8, slope = -0.15, color = "red")

The fit results are shown in Table 2.3.

The SSE for this line is 0.2727, which is lower than the SSE for the previous line, indicating a better fit.

While we could try additional lines to achieve a lower SSE, there are infinitely many possibilities since \(\beta_0\) and \(\beta_1\) can take any real value.

Using Calculus, we can attempt to minimize the SSE for the generic line \[\begin{align*} \hat{y} = b_0 +b_1 x \end{align*}\]

We will denote the sum of the squared distances with \(Q\): \[ Q=\sum \left(y_i-\hat{y}_i\right)^2 \tag{2.3}\]

We determine the “best” line as the one that minimizes \(Q\).

TipFor those who want to see the math:

To minimize \(Q\), we differentiate it with respect to \(b_{0}\) and \(b_{1}\): \[\begin{align*} \frac{\partial Q}{\partial b_{0}} & =-2\sum \left(y_{i}-\left(b_{0}+b_{1}x_{i}\right)\right)\\ \frac{\partial Q}{\partial b_{1}} & =-2\sum x_{i}\left(y_{i}-\left(b_{0}+b_{1}x_{i}\right)\right) \end{align*}\]

Setting these partial derivatives equal to 0, we have \[\begin{align*} -2\sum \left(y_{i}-\left(b_{0}+b_{1}x_{i}\right)\right) & =0\\ -2\sum x_{i}\left(y_{i}-\left(b_{0}+b_{1}x_{i}\right)\right) & =0 \end{align*}\] Looking at the first equation, we can simplify as \[\begin{align*} -2\sum \left(y_{i}-\left(b_{0}+b_{1}x_{i}\right)\right)=0 & \Longrightarrow\sum \left(y_{i}-\left(b_{0}+b_{1}x_{i}\right)\right)=0\\ & \Longrightarrow\sum y_{i}-\sum b_{0}-b_{1}\sum x_{i}=0\\ & \Longrightarrow\sum y_{i}-nb_{0}-b_{1}\sum x_{i}=0\\ & \Longrightarrow\sum y_{i}=nb_{0}+b_{1}\sum x_{i} \end{align*}\]

Simplifying the second equation gives us \[\begin{align*} -2\sum x_{i}\left(y_{i}-\left(b_0+b_1x_{i}\right)\right)=0 & \Longrightarrow\sum x_{i}\left(y_{i}-\left(b_0+b_1x_{i}\right)\right)=0\\ & \Longrightarrow\sum x_{i}y_{i}-b_0\sum x_{i}-b_1\sum x_{i}^{2}=0\\ & \Longrightarrow\sum x_{i}y_{i}=b_0\sum x_{i}+b_1\sum x_{i}^{2} \end{align*}\]

The two equations \[ \begin{align} \sum y_{i} & =nb_0+b_1\sum x_{i}\nonumber\\ \sum x_{i}y_{i} & =b_0\sum x_{i}+b_1\sum x_{i}^{2} \end{align} \tag{2.4}\]

are called the normal equations.

We now have two equations and two unknowns (\(b_0\) and \(b_1\)). We can solve the equations simultaneously. We solve the first equation for \(b_0\) which gives us \[\begin{align*} b_0 & =\frac{1}{n}\left(\sum y_{i}-b_1\sum x_{i}\right)\\ & =\bar{y}-b_1\bar{x}. \end{align*}\]

We now substitute this into the second equation in Equation 2.4. Solving this for \(b_1\) gives us \[\begin{align*} & \sum x_{i}y_{i}=b_0\sum x_{i}+b_1\sum x_{i}^{2}\\ & \quad\Longrightarrow\sum x_{i}y_{i}=\left(\bar{y}-b_1\bar{x}\right)\sum x_{i}+b_1\sum x_{i}^{2}\\ &\quad\Longrightarrow b_1=\frac{\sum \left(x_{i}-\bar{x}\right)\left(y_{i}-\bar{y}\right)}{\sum \left(x_{i}-\bar{x}\right)^{2}}. \end{align*}\]

The equations \[ \begin{align} b_0 & =\bar{y}-b_1\bar{x}\\ b_1 & =\frac{\sum \left(x_{i}-\bar{x}\right)\left(y_{i}-\bar{y}\right)}{\sum \left(x_{i}-\bar{x}\right)^{2}} \end{align} \tag{2.5}\] are called the least squares estimators.

TipFor those who want to see the math:

To show these estimators are the minimum, we take the second partial derivatives of \(Q\): \[\begin{align*} \frac{\partial^{2}Q}{\partial\left(b_{0}\right)^{2}} & =2n\\ \frac{\partial^{2}Q}{\partial\left(b_{1}\right)^{2}} & =2\sum x_{i}^{2} \end{align*}\] Since these second partial derivatives are both positives, then we know the least squares estimators are the minimum.

The least squares estimators in Equation 2.5 can be expressed in simpler terms if we let \[\begin{align*} SS_{xx} &= \sum \left(x_i-\bar x\right)^2 \\ SS_{xy} &= \sum \left(x_i-\bar x\right)\left(y_i - \bar y\right) \end{align*}\]

The least squares estimates become \[\begin{align} {b_1=\frac{SS_{xy}}{SS_{xx}}}\\ {b_0=\bar{y}-b_1\bar{x}} \end{align}\]

To recap: The straight line model for the response \(y\) in terms of \(x\) is \[\begin{align*} {y = \beta_0 + \beta_1 x + \varepsilon} \end{align*}\]

The line of means is \[\begin{align*} {E(y) = \beta_0 + \beta_1 x } \end{align*}\]

The fitted line (also called the least squares line) is \[\begin{align*} {\hat{y} = b_0 + b_1 x } \end{align*}\]

ExampleExample 2.4: Interpreting a fitted line

Suppose the fitted line for a dataset is \[ \hat y = 1.8 - 0.15x. \]

The intercept is \(b_0=1.8\). This is the predicted value of \(y\) when \(x=0\). Whether this interpretation is meaningful depends on whether \(x=0\) is reasonable in the context of the data.

The slope is \(b_1=-0.15\). This means that for each 1-unit increase in \(x\), the predicted value of \(y\) decreases by 0.15 units.

For example, when \(x=6\), the fitted value is \[ \hat y = 1.8 - 0.15(6) = 0.9. \]

The fitted line gives predictions from the sample data. It is our estimate of the unknown line of means.

For a given data point, \((x_i, y_i)\), the observed value of \(y\) is denoted as \(y_i\) and the predicted value of \(y\) is obtained by substituting \(x_i\) into the prediction equation: \[\begin{align*} {\hat{y}_i = b_0 + b_1 x_i } \end{align*}\]

The deviation of the \(i\)th value of \(y\) from its predicted value, called the \(i\)th residual, is \[\begin{align*} { \left(y_i-\hat{y}_i\right) } \end{align*}\] Thus, SSE is just the sum of the squared residuals.

NoteError terms vs. residuals

The random error term \(\varepsilon_i\) and the residual \(y_i-\hat y_i\) are closely related, but they are not the same thing.

  • The error term \(\varepsilon_i\) is the unobserved difference between an observation and the true mean response: \[ \varepsilon_i = y_i - E(y_i). \]
  • The residual is the observed difference between an observation and the fitted value from our sample model: \[ e_i = y_i-\hat y_i. \]

In practice, we do not know the true mean response \(E(y_i)\) because we do not know the true parameters \(\beta_0\) and \(\beta_1\). We use residuals as observable estimates of the errors after fitting the model.

ExampleExample 2.5: Interpreting a residual

Using the first trial line in Equation 2.1, the observation with \(x=1\) has observed value \(y=2\) and predicted value \(\hat y=1.8\). The residual is \[ y-\hat y = 2-1.8 = 0.2. \]

Because the residual is positive, the observed point is above the fitted line. If a residual is negative, the observed point is below the fitted line. A residual close to zero means the fitted line predicted that observation fairly well.

Least squares chooses the line that makes the sum of squared residuals as small as possible. It does not make every residual equal to zero; that would usually be impossible unless all points fell exactly on one straight line.

2.4 Recap

Keyword Definition
Simple linear regression A regression model that relates a response variable \(y\) to one predictor variable \(x\).
First-order linear model A straight-line probabilistic model of the form \(y=\beta_0+\beta_1x+\varepsilon\).
Mean response The expected value of \(y\) for a given value of \(x\), written as \(E(y)=\beta_0+\beta_1x\).
Random error The part of an observed response not explained by the mean response function.
Parameter An unknown population quantity, such as \(\beta_0\) or \(\beta_1\).
Estimate A value computed from sample data to approximate a parameter, such as \(b_0\) or \(b_1\).
Intercept The predicted response when \(x=0\); it should only be interpreted literally when \(x=0\) is meaningful in context.
Slope The expected change in the predicted response for a 1-unit increase in \(x\).
Fitted line The estimated regression line \(\hat y=b_0+b_1x\) obtained from sample data.
Predicted value The value \(\hat y_i\) produced by the fitted line for a particular \(x_i\).
Residual The vertical difference between an observed value and its predicted value, \(y_i-\hat y_i\).
SSE The sum of squared residuals, \(\sum (y_i-\hat y_i)^2\), used to measure overall lack of fit.
Least squares line The fitted line that minimizes SSE among all possible straight lines.

2.5 Check your understanding

NoteProblems

  1. Why is the straight-line regression model called probabilistic rather than deterministic?

  2. In the model \(y=\beta_0+\beta_1x+\varepsilon\), what is the difference between the line of means \(E(y)=\beta_0+\beta_1x\) and an individual observed value of \(y\)?

  3. Why do residuals measure vertical distances rather than horizontal distances from the fitted line?

  4. Why does least squares minimize squared residuals instead of simply adding the residuals themselves?

  5. Explain the difference between \(\beta_0,\beta_1\) and \(b_0,b_1\).

  6. If one fitted line has a smaller SSE than another fitted line for the same data, what does that tell us? What does it not tell us?

  7. What is the difference between an error term \(\varepsilon_i\) and a residual \(e_i=y_i-\hat y_i\)? Why can we observe one but not the other?

  8. Suppose a fitted line is \(\hat y = 12 + 4x\). Interpret the slope in context-free language. What should you check before interpreting the intercept?

TipSolutions

  1. Probabilistic, not deterministic. The model is probabilistic because it allows observations with the same value of \(x\) to have different values of \(y\). The line describes the mean response, while the error term represents random variation around that mean.

  2. Mean response vs. observed response. The line \(E(y)=\beta_0+\beta_1x\) describes the average or expected value of \(y\) at a given \(x\). An individual observed value also includes random error, so it may fall above or below the mean response line.

  3. Why vertical distances. Regression is used to predict \(y\) from \(x\), so prediction error is measured in the response direction. For a given \(x_i\), the fitted line gives one predicted value \(\hat y_i\), and the residual \(y_i-\hat y_i\) measures how far the observed response missed that prediction.

  4. Why square residuals. If we simply added residuals, positive and negative residuals could cancel each other out, making a poor fit look better than it is. Squaring residuals makes all contributions nonnegative and gives larger errors more influence.

  5. Parameters vs. estimates. The symbols \(\beta_0\) and \(\beta_1\) represent the unknown population intercept and slope. The symbols \(b_0\) and \(b_1\) are estimates computed from the sample data. Since we usually do not know the true population line, we use the fitted line based on \(b_0\) and \(b_1\).

  6. Interpreting smaller SSE. A smaller SSE means the fitted line has a smaller total squared residual error for that dataset, so it fits those observed points better by the least squares criterion. It does not automatically prove that the model is appropriate, that the relationship is causal, or that future predictions will be accurate.

  7. Error vs. residual. The error term \(\varepsilon_i\) compares \(y_i\) to the true mean response \(E(y_i)\), which depends on the unknown population parameters. The residual compares \(y_i\) to the fitted value \(\hat y_i\), which we compute from the sample data. We can observe residuals after fitting a model, but the true errors remain unobserved because the true regression line is unknown.

  8. Interpreting slope and intercept. The slope of 4 means that for each 1-unit increase in \(x\), the predicted value of \(y\) increases by 4 units. Before interpreting the intercept, check whether \(x=0\) is meaningful and within the range of the data. If \(x=0\) is unrealistic or far outside the observed data, the intercept may be needed mathematically but not useful as a practical interpretation.
